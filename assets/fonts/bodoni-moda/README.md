# Bodoni Moda Italic

Fuente variable original de Google Fonts, distribuida con SIL Open Font License 1.1 (ver OFL.txt).

- Fuente: https://github.com/google/fonts/tree/main/ofl/bodonimoda
- Archivo: BodoniModa-Italic[opsz,wght].ttf (renombrado en el proyecto para simplificar la URL; contenido sin modificar).
- Proyecto original: https://github.com/indestructible-type/Bodoni

Se usa en peso 900 e inclinada como alternativa visual a FundRunO. No es la misma fuente. Los controles «Letra de los versículos» permiten volver a la letra original. La selección se conserva en este navegador y se comparte entre versículo diario, memorización y galería. No cambia sermones ni devocionales.

«Descargar con versículo NVI» crea un PNG con fondo, pasaje NVI y crédito del proveedor. Requiere acceso NVI activo; si la consulta falla, no descarga una imagen con una cita de otra versión. El botón «Descargar» conserva la descarga del fondo original.
