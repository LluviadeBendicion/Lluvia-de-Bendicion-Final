# Fuentes multimedia pendientes

## Videos
- Playlist oficial de YouTube: pendiente URL/ID.
- Página/servicios de Facebook: pendiente URL oficial.
- Originales LLDB: pendiente catálogo.

## Wallpapers
Usar únicamente imágenes aprobadas en el panel LLDB antes de publicación.

## Redes
Instagram, Facebook y YouTube deben enlazarse solo cuando se proporcionen las URLs oficiales.
